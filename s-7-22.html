ጀህራብዓይ ክፋል › ምዕራፍ ሰቦዕ ለትፈናተ ከሊማትጽበ'ጥ

7.22መዐደኒ

ናፍረት = ለተረደ: ለሬመ: ለዐከ ወክቡድ ጾጸር ለረፈዕ ዕጫይ ፈላቅ እት ገብ'እ: መብዝሑ ዶል ምን ወይቦ (ጸሐት) ወገሮበ ቤት ለብዕድ ረፈዕ።

ቶርማን = ለተረደ ዕክክናሁ ምግባይ አው አክል ናፍረት ለገብ'እ: ዕጫይ ማሪ- ቱ። መብዝሑ ዶል ምን ጸሐት ገብ'እ።

ለክፍ = ኢቀጢን ወኢረዪም ምግባይ እት ገብ’እ: ምን ቶርማን ኢለሐምቅ። ዕጫይ ማሪ ወረዪም ቱ። አድዐም = ሪሙ አስክ 2.5 ምትር ገብ’እ: ምግባይ ዕክክነ ለቡ ሸበህ ማሪ ወፍልቅ ለቡ ዕጫይ ቱ። አስሁም = ማሪ ምን ሰለስ ምትር ለኢለሐጭር: ትሩድ ወብዞሕ ዕኩክ ለኢገብአ ዕጫይ።
በሪም = ምን ሰለስ አው ክልኤ ሸርባይ ለገብ'እ: እግል አሲር ዕጨይ ለነፈዕ: ዕክክናሁ አክል ጸገት ለገብ'እ: መብዝሑ ዶል ምን ለሸም: ብብያ: ሻውረ: ሕጡም ገብ'እ።

ደፋ’ኒ = ብዞሕ ማሪ ኢኮን። ምን ጭቅመት እዴ ' ለኢለዐክክ ዕጨይ ቀጠይን ቱ። ምን ለሸም: ብብያ: ሻውረ ወሕጡም ገብ’እ። ወእበ" ዕኩክ እንክሩ ልትወተድ።

ቀላቢ = ምብዝሑ ዶል ምን ዕጨይ ማሪ ወቀጠይን እት ገብ'እ: ምን ደፋኒ ለኢዐክክ ቱ። ወለዕኩክ እንክሩ ለዐል ልትአሰር ወእግል ደፋኒ ልትከበት።

ጥላይ = ምን ድርቅ ለልትሸቄ ድንስ ሐብል።

ገሊል = እት መሓዛት ወጋድሞታት ለበቅል ሰዐር እት ገብ'እ: ቀጠፍ ብዞሕ አለቡ ወአብራክ'
ለበዝሐ እቱ ቱ። ትሩዱ ወከራብ ሰዐር ጫፍቅ ፑቱ።

ዘገት = ምን ክምኩም ገሊል ምን ለዐል አስክ ተሐት እብ ወጠ ትትከፊሬ መእሰር ሰዐር: ቅያስ ሐቱ' አመት ለገብ’እ ርሕብነ እቡ' ትትሸቁ።

አሳስ = መአንበት አው ትንቡረትለ ቤት ቱ።

ስምጥ = ለሬመ እንክር ናይለ ቤት ቱ። ወአርበዕ ርክን ቡ።
ቆበዐት = ለሐጭረ እንክርለ ቤት እትገብ’እ: መባትክ ትክል ለቡ ሐምስ ርክን ትርኤ እቱ።
ቅጽዕ = እት ምግብ ቤት እግል ቤት እት ክልኤ
ለክፍልቱ።
ጣቀት = ቤባይ ንኡሽ መብዝሑ ዶል አንስ
ለልትነፈዐ እቡ’ቱ።
ባብ = ርሒብ ወፋይዩሕ እትገብ’እ: እሙር
ባብለ ቤት ቱ።
ባሕሪ = ለቤት በሐር ትገኔሕ ገብአት ምንገብ'እ ባሕሪ ልትበህል።

ቁብሊ = ለቤት ቅብለት ገኔሕ ገብአት ምንገብ'እ: ሐብልክ = ሓባል ለለአትካብት ነፈር: ዶል ሽቅል ለልትላከው እበ" ስሜት።
ሙዓልም = ምን አሳስለ ቤት አስክ ኣክር ለሐብር ወለመሬሕ መሃንድስቱ።
ቅያስ ቤት = ክልኤ ባባ አርበዕ ናፍረተ:: ሐቱ' ባባ ሰለስ ናፍረተ: ክላኤ ናፍረተ ልትበህል። አርበዕ ናፍረተ = ምን 12 —15 ምትር ለትገብ’እ: ሰለስ ኦደት ለባተ። ምድልስ: ቤት ምግብ: ወቤት ከረስ ህይ ልትበህል። ምጅልስ እግል ሰብ: ቤት ምግብ እግል አንስ ወአ፫ኒት: ከርስ ቤት ላኪን ናይ አንስተ። ምጅልስ ወቤት ምግብ: ክልምነ’ን ባብ ብእተን። ቤት ከርስ ላኪን ጣቀት ሌጠ ብእተ። ሐት-ሐቱ’' ዶልመ ቤት ምግብ ጣቀት ክም ወሱክ ትገብ’እ እተ። እለ"” ቤት እለ” እብ አርበዕ ናፍረት ትሸቁ።

ሰለስ ናፍረተ = እብ ሰለስ ናፍረት ትትሸቁ። ምድልስ ወቤት ከርስ ብእተ። ወኦሮ ባብ ወጣቀት ብእተ።

ክልኤ ናፍረተ = ምን አርበዕ አስክ ስስ ምትር ለገብ’እ ለሪመ ሐቱ' ኦደት ቤት ተ። ወሐቱ' ባብ በ። እለ"” እብ ክልኤ ናፍረት ለትሸቄተ።

ጣነቦት = አልበሶት (ገልበቦት) ቤት ኣብ ገሊል ምን በረ ለገብ’እ ጣነቦት ቱ። ምን ጅወ (ከርስ) እብ ተኮብ ዶል ገልብበ: ጣነቦት እብ ተኮብ ዎክ ተደራብ ልትበህል።

መኻጥ = አክል አመትለገብ'እ: ምን ተንዲኖ ቀጢን ሽቂይ: ዕጉን ሐጺን አፍ ብሉሕ ወአንገብ ፍሩቅ ክም እብረት እት ተድሪብ ተኮብ ከይጦ እቡ’። መሕፈሪ = መሳር እት እንቱ: ለዕጫዩ ማሪ ወትክ ብህል ቅያስ ምትር ለገብ’እቱ።
ሕለቅ = ጅድንስ ሐብል ምን ትኩም እንክር ከዐሌ ለልትሸቄ እት ተድሪብ ቤት ኸያጠት tht ልትነፈዖ እቡ'።
